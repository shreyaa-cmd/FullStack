# JS Quiz Arena

A quiz app made with plain HTML, CSS and JavaScript.

## Features

- One question at a time with 4 clickable options, a progress line (Q 3/10) and a live score
- After a click the chosen option turns green or red, the correct one is shown, the explanation appears and the other options get locked
- Next and Restart buttons, and at the end a final score with a rating message
- 30 second countdown for each question, when it hits 0 the question locks and the answer is revealed
- "Review wrong answers" screen at the end

## How to run

Open `index.html` in your browser.
